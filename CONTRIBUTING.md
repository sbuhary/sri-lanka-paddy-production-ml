# Contributing

This repository is a student learning activity for IT 5514 Applied Machine Learning.

To reproduce results, install dependencies with `python -m pip install -r requirements.txt`,
then run `python train_models.py`. Run the UI using `python -m streamlit run app.py`.

Keep changes reproducible, document new model settings, and avoid committing virtual
environments, generated CatBoost logs, secrets, or large trained model binaries.
