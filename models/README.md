# Generated models

Run `python train_models.py` from the project root to generate the model artifacts.
The `.joblib` files are intentionally not tracked in Git to keep the repository small.

The dashboard also needs `metadata.json`, `metrics.csv`, and `test_predictions.csv`.
These are generated by the training script and can be committed after training.

Never load model files downloaded from untrusted sources: joblib/pickle loading can execute code.
